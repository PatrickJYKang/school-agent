# hi!

I thought it was necessary to set up a communications channel for this work group/think tank, such that we can share reading material, ideas, current work/projects/progress, and whatever else, which me and Dr. Dzula did on Wednesday. This sharepoint site is designed to hold all of that, I think it's a flexible medium for this kind of thing. This is a welcome document so everyone knows what this is and how to work with it.

## Navigation

The main page has links to two lists:
 - **Project list**, a list of ongoing and past (and proposed?) projects.
 - **Annotated Bibliography**, an annotated bibliography/reading list.

And a section with all documents, including this one. Perhaps everything, be it plans, ideas, etc, will go in repo root for now, but we can organise at some point.

And an activity section that I believe automatically populates with updates to the above.

The right side bar is currently a template artefact and doesn't do anything useful.

## What to do

The point of this thing existing is to encourage a higher volume of discussion and collaboration and flow of ideas within the group. In the spirit of that, if you have an idea, be it a completely undeveloped thought or an implemented prototype, please post it. From there we can then read each others' work and comment on it (next step for this is to establish a communications/commenting channel). Obviously this is not an obligation to read or post although please do commit to treating everyone's ideas with due respect.

Hopefully we can organise the multitude of projects that exist in this space on this site as well, though I personally regard the exchange of ideas as a more central purpose of this site, organisation is certainly helpful and helpful to include here. In that sense please if you are leading a project actively update its entry on this site.

While sharepoint does store version and authorship history (I think), please do, unless you really don't want to, sign off your stuff (like below), particularly if it's a file that could use further discussion. Also, don't upload whole code repositories or databases into this project directory, put them on GitHub and link to them instead. Thanks!
