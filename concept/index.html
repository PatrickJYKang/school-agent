01 / A limited first release

Configure. Connect.
Tune for education.

Configure existing capabilities

The school manages access.

School sign-in, approved models and tools, staff/student groups, account allowances, and clear data settings.

  • Reuse LibreChat’s authentication and access controls
  • Evaluate its existing admin panel
  • Default to school-approved helpers and connections
  • Keep public sharing off in the pilot
Add a focused integration experience

Bring in the right Canvas context.

Select a course, assignment, and rubric from material the person can already access. Show what the assistant used and link the answer to that material.

  • Selected course-content reads
  • Per-user connection and institution-approved tools
  • Clear context chips and source inspection
  • Continue using the existing Microsoft 365 file picker
Small user-facing improvements

Make help easier to direct.

A few good defaults: study coaching, feedback on a draft, and teaching preparation. Educators can share narrowly scoped helpers using existing agent permissions.

  • Hint, explain, and feedback choices
  • Visible teacher guidance for the selected activity
  • Easy access to approved analysis and research tools
  • Portable Markdown exports
02 / The everyday experience

Choose the material.
Ask for useful help.

“Help me understand this assignment.”

A student opens a school-provided chat, chooses Study coach, and adds a Canvas assignment and rubric. The assistant can read that selected context, explain concepts, and use approved tools to check data.

A teacher can prepare feedback or publish a helper for a class group. The school manages access and available capabilities through LibreChat’s existing controls.

A familiar conversation
  1. Choose an approved helper.
  2. Add selected Canvas or Microsoft 365 material.
  3. Ask a question; inspect sources and tool activity.
  4. Continue the conversation or export the useful text.

04 / Keep the pilot bounded

One school deployment.
A manageable set of changes.

Keep in the pilot

  • School accounts and approved AI capabilities
  • Selected Canvas assignment and rubric context
  • Microsoft 365 attachments through existing integration
  • A small shared library of education helpers
  • Simple learning guidance, source cues, and exports

Keep documented for later

The shared task folders, parallel personal agents, coordinated file updates, and richer artifact collaboration remain in the earlier exploration. GitHub, Slack, and Outlook connections can be evaluated after the core pilot.

Course management, grading, submission, and document editing stay in existing systems.
