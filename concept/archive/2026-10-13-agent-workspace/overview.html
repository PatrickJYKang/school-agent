A broader school agent workspace.

This is a preserved exploration. The current first release is a limited LibreChat fork. These ideas remain documented for possible later work.

The earlier concept centered on one task folder shared by students, educators, and their agents, with OneDrive preferred and GitHub as an alternative.

  • Each participant has a separate conversation and private agent context.
  • Agents prepare independent changes; the harness integrates compatible updates into the shared files. Ambiguous changes become ordinary review decisions.
  • Markdown is the default prose format. Images are separate assets; comments and revision history are separate metadata.
  • DOCX and PDF are read-only sources. Requests to revise their text move the work into Markdown, without a formal source-to-draft relationship.
  • Shared agent activity shows tasks, progress, outputs, and decisions. It avoids exposing branches and merge mechanics.
  • Native storage permissions and school management govern access. GitHub permissions operate at repository scope.

The open questions include reliable cloud synchronization, private working copies, concurrent publication, native permissions, recovery, and the cost of maintaining a new harness. Those requirements expanded the product beyond the present pilot.
